# Парло — кликабельный прототип (alive-parrlo-proto)

**Открыть:** https://muratpod.github.io/parrlo-chat-mockups/alive-parrlo-proto/. На iPhone прототип занимает весь экран, на компьютере показан в рамке 402×874.

Прототип: **ответы заранее заготовлены**. Сервера и микрофона нет, всё симуляция. Помогает выбрать между вариантами из [alive-parrlo-front](../alive-parrlo-front/).

## Что нажать
1. **Главная:** нажмите на Парло — он отреагирует. С непрочитанным он радуется, без него — в покое.
2. **«Парло» под ним → чат.** Напишите сообщение или нажмите подсказку. Парло «думает» 1,6 с (со словом «найди» — «ищет» 2 с), потом печатает заготовленный ответ. Парло в шапке меняет режим вместе с ответом.
3. **«Нажмите и говорите» → экран голоса.** Удерживайте кнопку (или нажмите один раз) — «слушает». Отпустите — «думает», потом «говорит» с субтитрами. Во время разговора смотрит прямо на вас. Вопрос и ответ попадают в чат.
4. **Назад** — в чат и на главную.

Над телефоном (на iPhone — полоска сверху): **A / B / C / Профиль (сейчас в TestFlight)**. Шестерёнка или панель слева — Reduce Motion, экономия энергии, непрочитанное, размер 104/80 pt, взгляд за пальцем, озвучка браузера (по умолчанию выкл.).

Ссылка с параметрами: `?v=a|b|c|p`, `rm=1`, `low=1`, `unread=0`, `size=80`.

## Файлы
| Файл | Что |
|---|---|
| `index.html` | Оболочка, стили прототипа. Компоненты — `../components.css`, `../tokens.css` (как во frames/ru-home-chats, ru-parrlo, ru-parrlo-voice) |
| `proto.js` | Сценарий: экраны, заготовленные ответы, голос, панель демо |

Риги не скопированы, подключены относительными ссылками: `../alive-parrlo-front/front-core.js`, `front-svg.js`, `front-3d.js` (тот загружает свой `three.min.js` только при выборе B) и `../alive-parrlo/alive.js` + `parrlo-rig.svg` для профиля.

Тексты на «вы». В макетах frames пока на «ты» — их не трогали.
