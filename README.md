# Parrlo Chat — интерфейсные макеты

Макет интерфейса, не продукт. Экраны мессенджера Parrlo Chat на трёх языках (RU / ES / EN) для разных устройств.

**Просмотр:** https://muratpod.github.io/parrlo-chat-mockups/

- `index.html` — просмотрщик (язык, экран, устройство, размер текста)
- `frames/` — HTML-кадры экранов
- `png/` — готовые изображения экранов
- `persona/` — варианты персонажа
- `SPEC.md`, `COMPONENTS.md` — описание экранов и компонентов

Все экраны — черновики для обсуждения; тексты, помеченные «не утверждено», не финальные.
