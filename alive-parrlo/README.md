# Живой Парло (alive-parrlo)

Макет поведения маскота Parrlo Chat — **не прод-код**. Образ 1 (SPEC §23), разобранный на части, и правила, по которым он двигается: покой, «думает», «ищет», радость, «говорит», «слушает». Сделано по образцу живого Paddy из Padelada (build 107, `src/features/paddy/alive/`, PR #782).

**Превью:** https://muratpod.github.io/parrlo-chat-mockups/alive-parrlo/

| Файл | Что внутри |
|---|---|
| `parrlo-rig.svg` | Парло, разобранный на именованные группы, точки вращения в `data-pivot` |
| `index.html` | Превью: переключатель режимов, lowPower, Reduce Motion, пауза, жесты, таблицы, телефоны 402 / 375 |
| `alive.js` | Справочная логика: позы, формулы движений, планировщик, уровни работы. Все числа — в объекте `T` и в функциях `MOTION`, `GESTURE_POSE`, `ambient` |
| `README.md` | Этот файл |

Статус: **не утверждено** (позы «покой», «ищет», «радость» и размер 104 / 80 ждут решения Мурата).

## 1. Главное правило

- Двигаются **только `transform` (translate / rotate / scale) и `opacity` групп**. Пути (`d`), цвета, радиусы не меняются никогда.
- Поза — набор чисел. Каждый кадр поза считается из времени (чистые функции), из позы получаются transform и opacity частей. Никаких неявных анимаций SwiftUI на каждый параметр.
- Три позы v1 собираются из частей **точно**: сверка по пикселям при 240 px — «говорит» 0 отличий; «думает» 0 пикселей с отличием > 40/255; «слушает» 3 пикселя на кончиках гребня (скругление пера при scaleY).

## 4. Движение режимов (уровень full)

`sin(P)` — синус с периодом P секунд; `пульс(u)` — полпериода `sin²`, полпериода 0 (как `pulse` в Paddy). Значения добавляются к ключевой позе. Точные формулы — `MOTION` в `alive.js`.

| Режим | Когда | Движение |
|---|---|---|
| **Покой** | по умолчанию | Фон ×1 (§5) + жесты (§6). 15 к/с без жеста, 30 к/с во время жеста |
| **Думает** | Парло готовит ответ | голова −3° ± 1.5° sin 3.3 с · наклон ± 1° sin 5.2 с · взгляд x +1.5 ± 1.0 (sin 4.3 с), y −1.5 ± 0.5 (sin 2.9 с) · перо 3 «постукивает» +3°·max(0, sin 1.35 Гц)² · точки: пульс 1.26 с, сдвиг 0.42 с между точками, opacity база × (0.35…1), scale 0.85…1 от центра точки |
| **Ищет** | Парло ищет по чатам / памяти | голова ± 5°, сдвиг ± 3 ед. (1.17 pt), sin 2.4 с · взгляд ± 4.5 ед. (1.76 pt) сглаженным меандром `tanh(4·sin)/tanh(4)`, 2.4 с · клевок −1.5 ед. (0.59 pt)·|sin 1.2 с| · перья ± 3° sin 0.6 с, фаза −0.5 рад на перо · блик: поворот −100° → 0° за 1.2 с (smoothstep), opacity 0.9·пульс(t/1.2) |
| **Радость** | есть непрочитанное | подскоки −7 ед. (2.73 pt)·|sin 1.1 Гц| · в воздухе тело scaleY +2 %, scaleX −1 % · качание ± 3° sin 2.4 с · крыло ± 10° 2.2 Гц · перья ± 4° 2.2 Гц, фаза −0.7 рад · подклювье ± 3° 2.2 Гц |
| **Говорит** | озвучивает ответ | «слоги» `o = max(0, sin 4.2 Гц)·(0.6 + 0.4·sin 1.3 с)` · подклювье −3° + 13°·o (−3…+10°) · надклювье −2.5°·o · голова ± 1.5° 2.1 Гц · наклон ± 0.6° sin 3.1 с · дуги: пульс 0.9 с, внешняя на 0.15 с позже, opacity 0.4…1 (внешняя ×0.62), scale 0.96…1.02 от 188, 126 |
| **Слушает** | диктовка | голова −2° ± 1.2° sin 2.8 с · перья ± 1.5° sin 1.9 с · дуги «к голове»: пульс 1.4 с, внешняя первой, внутренняя через 0.28 с, opacity 0.4…1, scale 1.04…0.98 от 46, 112 |

**Приоритет на главной:** joy (есть непрочитанное) > busy (think / search) > idle — как `pickMode` в Paddy. Если сервер не отличает поиск от ответа — показывать think. speak / listen — для зоны диктовки.

**Смена режима:** 0.45 с. Веса режимов идут к цели линейно, поза смешивается через smoothstep. Жест покоя гаснет за 0.25 с при уходе из покоя. После busy → idle: пауза 1.6 с и обязательный кивок («готово»). После joy → idle: обычная первая пауза 2 с.

## 6. Жесты покоя

Только в режиме «покой» и только на уровне full. Пауза между жестами 3–8 с, первый — через 2 с после появления и после возврата из паузы, один жест подряд не повторяется, «не чаще» считается от старта. Огибающая: вход 0.2 с, выход 0.3 с (smoothstep). Ключи `время с → значение`; out = `1 − (1 − u)²`, in = `u²`, без пометки — quad in-out.

## 7. Уровни работы и частота кадров

Как `resolveState` / `tickHz` в Paddy.

| Уровень | Когда | Что идёт | Кадров/с |
|---|---|---|---|
| `frozen` | за краем экрана, приложение не активно, главная не в фокусе | ничего | 0 (цикл выключен, таймеры стоят) |
| `reduce` | Reduce Motion | статичная поза, смены — кроссфейдом, моргание и реквизит — прозрачностью | 15 только пока меняется прозрачность; покой и радость между морганиями — 0 |
| `lowPower` | режим энергосбережения | моргание + фон (§5), без жестов и без движения режима | 15 |
| `full` | всё остальное | всё | 30 в жестах и не-покое; 15 в покое без жеста |

Порядок проверки: frozen → reduce → lowPower → full.

### Пауза вне экрана и в фоне
- **За краем:** сцена целиком ушла за край прокрутки (видимая часть 0, как в Paddy — «ушёл больше чем на 100 % своей высоты»). Без IntersectionObserver на iOS: `onScrollGeometryChange` / `GeometryReader` в `ScrollView`, условие `stageMaxY < 0`.
- **Фон:** `scenePhase != .active` (фон, шторка, переключатель приложений).
- **Не в фокусе:** поверх открыт чат, лист «+» (`home-menu`), настройки; ушли на другую вкладку (`onDisappear` / `isPresented`).
- **Возврат:** поза сразу целевая (без «доигрывания» перехода), жест сброшен, взгляд в центр, первый жест через 2 с.

### Экономия энергии (lowPower)
- Источник: `ProcessInfo.processInfo.isLowPowerModeEnabled` + уведомление `NSProcessInfoPowerStateDidChange` (в нативном SwiftUI это есть, в Paddy флаг передавал хозяин).
- Только моргание и фон, 15 к/с. Режим виден по ключевой позе: точки, дуги, клюв, веко стоят на месте.
- Отличие от кода Paddy 107: там в lowPower «занят» и joy продолжали своё движение на 15 к/с; здесь, по задаче, — только фон и моргание.

### Reduce Motion
- `@Environment(\.accessibilityReduceMotion)`.
- **Ничего не двигается:** transform во времени не меняется.
- **Смена режима:** статичная ключевая поза (§3) через кроссфейд прозрачности 0.25 с ease-in-out (два слоя; в SwiftUI — `.transition(.opacity)` + `.id(mode)`).
- **Моргание:** раз в 6–10 с, без двойных, слоем `lid-closed` (только opacity, те же 70 / 40 / 110 мс).
- **Признаки режима — только прозрачностью:** точки «думает» — пульс 1.6 с, сдвиг 1/3; дуги «говорит» — 1.2 с; дуги «слушает» — 1.6 с; блик «ищет» — 0.3…0.9, 1.6 с. Покой и радость — только моргание.
- Цикл кадров включается только на время моргания (≈ 0.45 с) и пока идёт пульс прозрачности.

## 9. Как собрать в SwiftUI (набросок)

```swift
struct ParrloAlive: View {
    var mode: ParrloMode            // .idle .think .search .joy .speak .listen
    var size: CGFloat               // 104 / 80
    var paused: Bool                // за краем, не в фокусе
    @Environment(\.scenePhase) private var phase
    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @State private var brain = ParrloBrain()   // планировщик: моргания, взгляды, жесты (§5–6)

    var body: some View {
        let frozen = paused || phase != .active
        TimelineView(.animation(minimumInterval: 1.0 / brain.hz, paused: frozen || reduceMotion)) { ctx in
            let pose = brain.pose(at: ctx.date, mode: mode)    // чистые функции из alive.js
            ParrloRig(pose: pose)                               // слои 240×240
                .frame(width: 240, height: 240)
                .scaleEffect(size / 240, anchor: .topLeading)
                .frame(width: size, height: size)
                .clipShape(Circle())
        }
        .accessibilityHidden(true)   // имя и статус даёт подпись сцены (кнопка «Парло, ИИ-секретарь…»)
    }
}
```

- Пути — `Path` из `d` в `parrlo-rig.svg` без изменений; группа `figure` = `.scaleEffect(0.9, anchor: .topLeading).offset(x: 12, y: 13.2)`.
- Каждая часть — слой во весь кадр 240×240 (кадр фигуры внутри `figure`), тогда `anchor` = «точка (фигура) / 240» из таблицы §2.
- Порядок модификаторов = порядок SVG справа налево. Пример: SVG `translate(0 lift) rotate(lean 110 170)` → `.rotationEffect(.degrees(lean), anchor: UnitPoint(x: 0.4583, y: 0.7083)).offset(y: lift)`. Перо: `rotate(a 90 54) · scaleY(s от 90 56)` → `.scaleEffect(x: 1, y: s, anchor: (0.375, 0.2333)).rotationEffect(a, anchor: (0.375, 0.225))`.
- Прозрачность — `.opacity()` на слое. Никаких `.animation()` на параметрах позы: всё считает `TimelineView`.
- 30 / 15 к/с: `minimumInterval` 1/30 или 1/15 (см. §7); при `frozen` — `paused: true`.
- Reduce Motion: `TimelineView` стоит; статичная поза; смена — `.id(mode).transition(.opacity)` 0.25 с; моргание — таймер на 6–10 с и короткий `withAnimation(.linear(duration: 0.07))` прозрачности `lid-closed`.
