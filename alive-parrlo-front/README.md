# Парло смотрит на вас (alive-parrlo-front)

Варианты объёмного Парло в анфас: он смотрит на собеседника, когда говорит и слушает. Это макет для выбора, **не прод-код**. Продолжение [alive-parrlo](../alive-parrlo/) (Парло в профиль; ту папку не трогали).

**Превью:** https://muratpod.github.io/parrlo-chat-mockups/alive-parrlo-front/

| Файл | Что внутри |
|---|---|
| `index.html` | Страница выбора: варианты A, B, C; режимы; Reduce Motion, экономия энергии, «следить за курсором»; телефоны (главная и экран голоса, Парло 104 pt) |
| `front-core.js` | Общая логика: поза-числа, режимы, моргание, взгляд за курсором / пальцем, жесты, пауза, кадры |
| `front-svg.js` | Варианты A и C: SVG-слои + проекция деталей на шар головы |
| `front-3d.js` | Вариант B: процедурная 3D-модель |
| `three.min.js` | three.js r187, частичная сборка (только нужные классы), MIT. Лежит локально, без CDN, 0.58 МБ |

Статус: **на выбор Мурату**. Рекомендация — **A**.

## Варианты

|---|---|---|---|

## Поза (общая для всех вариантов)

Каждый кадр поза считается как набор чисел (`front-core.js`), варианты только рисуют её.

| Поле | Смысл | Покой |
|---|---|---|
| `yaw`, `pitch`, `roll` | поворот головы: вбок (+ вправо, к клюву логотипа), вверх, наклон, ° | 0 |
| `lift`, `sy` | подскок (ед. 240, − вверх), сжатие тела | 0, 1 |
| `lx`, `ly` | взгляд −1…1 (зрачок до 4.2 / 3.6 ед. = 1.8 / 1.6 pt при 104) | 0 |
| `ps` | масштаб зрачка | 1 |
| `lid` | веко 0 открыто … 1 закрыто | 0 |
| `happy` | глаза-улыбки 0…1 (кроссфейд со зрачком) | 0 |
| `beak` | открытие клюва 0…1 | 0 |
| `c1..c3`, `cs` | перья хохолка, °; длина × | −24 / 0 / 24; 1 |
| `wl`, `wr` | крылья, ° (+ = поднять) | 0 |
| `dots`, `d1..d3`, `glint` | точки «думает», блик «ищет» | 0 |

Режимы, °/с и формулы — в таблице на странице и в `KEY` / `MOTION` (`front-core.js`). Главное:
- **Говорит:** взгляд прямо на вас (если нет курсора / пальца — в центр). Клюв по слогам `max(0, sin 2π·4.2t)·(0.6 + 0.4·sin 2π t/1.3)`. Кивок 2.5° на слог.
- **Слушает:** наклон −7° (как v1 listen), голова вперёд 3°, зрачки ×1.14, перья раскрыты, кивок раз в 2.8 с.
- **Моргание** (все режимы): 2.2–5.6 с, 18 % двойное, 70 / 40 / 110 мс.
- **Взгляд:** курсор или палец ±420 px от центра = край. Голова идёт следом до 12° вбок и 7° вверх-вниз. Сглаживание: зрачки 70 мс, голова 180 мс. Без движения 2.5 с — в центр. В покое без курсора — блуждание как у alive-parrlo.
- **Кадры:** 30 к/с; покой без жеста — 15; экономия энергии — 15 (моргание + дыхание, без жестов и движения режима).
- **Пауза:** за краем экрана и в фоне — 0 к/с. При возврате — сразу целевая поза, первый жест через 2 с.

### Reduce Motion
Статичная анфас-поза режима (в C тоже анфас, без поворота). За курсором не следит. Моргание — **прозрачностью** закрытого века (`lidc-*`, в 3D — дуга-«закрытый глаз»), раз в 6–10 с. Смена режима — кроссфейд 0.25 с (в 3D — снимок кадра поверх и его растворение). Точки «думает» и блик «ищет» — только прозрачностью.

## Риг A / C (SVG, viewBox 240)

Голова — шар R 60, центр (120, 104). Деталь на шаре задаётся азимутом и высотой. Поворот головы → точка `(x, y)` и нормаль `(nx, ny, nz)`. Плоская деталь рисуется матрицей «сжатие вдоль (nx, ny) в nz раз» (`squash` в `front-svg.js`). Дужки и перемычка — отрезок между двумя точками шара (`seg`). Меняются только `transform` и `opacity` групп.

| id | Деталь | Где на шаре / точка |
|---|---|---|
| `body`, `belly`, `wing-l`, `wing-r` | тело, светлая грудка, крылья (плечо 160) | тело поворачивается на 0.5·yaw; крылья на азимуте ±76° |
| `head` | голова: подскок + наклон вокруг «шеи» (120, 160) | — |
| `crest`, `crest-1..3` | хохолок, основание на макушке | аз 0°, выс 74° |
| `eye-l`, `eye-r` | стекло + оправа r 19 | аз ∓26°, выс 6° |
| `pupil-*`, `lid-*`, `lidc-*`, `happy-*`, `glint-*` | зрачок r 11.5 с бликами, веко, закрытое веко RM, глаза-улыбки, блик «ищет» | внутри `eye-*` |
| `temple-l`, `temple-r`, `bridge` | дужки и перемычка очков | отрезки между точками шара |
| `beak`, `beak-up`, `beak-low`, `mouth` | клюв, подклювье, рот | аз 0°, выс −24°; при повороте выступает сильнее |
| `dots`, `dot-1..3` | точки мысли | вне головы |

В SwiftUI: та же функция проекции → `.offset` + `.transformEffect(CGAffineTransform)` для сжатия, `.opacity` — для деталей, уходящих за силуэт.

## Открытые вопросы
1. Какой вариант берём: A (рекомендуем), B или C? Можно A + поворот из C.
2. B — модель процедурная; для продукта нужен художник по 3D и USDZ.
3. Анфас — для «говорит» и «слушает» на экране голоса, а на главной? Предложение: на главной тоже анфас (A), профиль остаётся в логотипе и маленьких аватарах.
4. Светлая грудка (`belly`) — новая деталь, её нет в v1; нужно ваше «да».
5. Размер на экране голоса: 104 pt, как в задаче (в прошлых макетах 96).
